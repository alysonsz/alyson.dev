## Trabalho selecionado

### Nucleus

**Produto autoral · Fintech · 2026**

Um ecossistema financeiro desenvolvido de ponta a ponta para consolidar dados de diferentes instituições e transformar informação financeira em contexto para tomada de decisão.

O projeto combina **React Native, .NET, Next.js, PostgreSQL, Open Finance e Docker**, conectando aplicativo, backend e experiência web em uma única arquitetura de produto.

No Nucleus, trabalhei desde a infraestrutura e integrações até a experiência visual, incluindo:

* consolidação de dados financeiros;
* integrações com Open Finance;
* arquitetura backend em .NET;
* aplicação mobile em React Native;
* experiência web em Next.js;
* mecanismos de concorrência, consistência e resiliência;
* testes automatizados de fluxos críticos;
* visualização e contextualização de dados.

**Destaques**

`< 200 ms` — latência em uma integração crítica após otimização da resolução de rede

`500+ E2E` — cenários automatizados cobrindo fluxos críticos, integrações e falhas

`Open Finance` — dados de múltiplas instituições consolidados em uma única experiência

**[Visitar o produto](https://nucleusbrasil.com.br)** · **[Ver engenharia](https://github.com/alysonsz/finance-nucleus-backend)**
