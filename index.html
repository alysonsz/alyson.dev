CASE 001

Nucleus

Um ecossistema financeiro que consolida dados, explica o que mudou e transforma informação em próximos passos.

Construí o Nucleus de ponta a ponta para transformar dados financeiros fragmentados em decisões claras, conectando aplicativo React Native, backend .NET e experiência web Next.js em uma única arquitetura de produto.

  • Unifiquei a vida financeira do usuário em uma única experiência, conectando diferentes instituições e fontes de dados por meio de Open Finance e construindo a infraestrutura necessária para consolidar contas, transações e patrimônio.
  • Construí a camada que transforma dados financeiros em inteligência, saindo de uma simples agregação de extratos para uma experiência capaz de organizar, contextualizar e destacar o que realmente importa para a tomada de decisão.
  • Projetei o produto para operar de forma confiável sobre integrações externas e dados financeiros sensíveis, com mecanismos de concorrência, consistência, resiliência e fallback capazes de preservar a experiência mesmo diante de falhas ou limitações dos serviços de terceiros.
